# Structural Biology Explorer

Interactive, in-browser teaching pages for the three main structural biology methods.

| Section | Page | Reference data |
|---|---|---|
| X-ray crystallography | [Diffraction at PXI](xray/) | PDB 9QBT · raw data doi:10.18430/M39QBT |
| Cryo-EM | [Frozen in the Beam](cryoem/) | PDB 5A1A |
| NMR | [Ubiquitin at 800 MHz](nmr/) | PDB 1UBQ · BMRB 6457 |

Live site: https://klausenhauser.github.io/structbio-explorer/

Each page is a single self-contained HTML file. To add one, drop it into the matching folder and add a card to `index.html`.
